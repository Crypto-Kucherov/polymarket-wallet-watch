# Polymarket Wallet Watch

Локальный инструмент для изучения публичных кошельков Polymarket:
рейтинг по PnL, открытые позиции, результаты закрытых позиций и список наблюдения.

**Статус:** расчёты проверены на контролируемых ответах API, интерфейс — в браузере.
Проверка живого API пока не завершена: прямое соединение было отклонено.
Демонстрационные кошельки и результаты вымышлены.

## Запуск

Нужен Node.js 22 или новее. Зависимостей npm нет.

```sh
git clone https://github.com/Crypto-Kucherov/polymarket-wallet-watch.git
cd polymarket-wallet-watch
node src/server.js
```

Откройте **http://127.0.0.1:8787**. Для демонстрации интерфейса:
**http://127.0.0.1:8787/?demo=1**.

Порт можно изменить: `PORT=8788 node src/server.js`.
Сервер доступен только на этом компьютере.

## Возможности

- До 50 лидеров рейтинга с выбором периода и категории.
- Поиск по имени, фильтр положительного PnL, просмотр публичного адреса.
- Прибыль закрытых позиций, доля прибыльных, profit factor и концентрация выигрышей.
- Текущая стоимость и нереализованный PnL открытых позиций.
- Кривая экономического PnL и 30 последних записей активности.
- Список наблюдения в браузере; отдельные списки для демо и живых данных.
- Обновление выбранного кошелька раз в минуту, пока страница видима и опция включена.

## Данные и ограничения

Используется официальный **Data API v2**. Каждое обращение — публичный GET.
Нет подключения кошелька, подписи сообщений или размещения ордеров.

Источники:

- [Рейтинг кошельков](https://docs.polymarket.com/api-reference/boards/get-the-trader-leaderboard)
- [Позиции](https://docs.polymarket.com/api-reference/wallet/list-positions-for-a-user-or-market)
- [Кривая PnL](https://docs.polymarket.com/api-reference/wallet/get-a-users-pnl-series)
- [Активность](https://docs.polymarket.com/api-reference/feeds/list-account-activity)
- [Переход на v2](https://docs.polymarket.com/migrate/data-api-v1-to-v2)

Рейтинг за день, неделю и месяц включает изменение оценки открытых позиций;
за всё время — реализованную прибыль. Эти значения не суммируются с выборкой
закрытых позиций. Объём API измеряется в долях и не используется как вложенный
капитал для расчёта ROI.

Закрытые позиции загружаются по времени последнего события, максимум 500 строк.
При ограничении страниц, повторном курсоре или ошибке показывается неполнота.
График и позиции охватывают весь кошелёк; фильтр категории относится к рейтингу.
Открытые позиции включают доступные архивные рынки и ещё не погашенные исходы;
неактивные рынки могут отсутствовать в API.

Доля прибыльных = положительные / (положительные + отрицательные) среди
загруженных закрытых позиций с известным результатом. Нулевые результаты
показаны отдельно. Позиция не равна сделке: возможны частичные выходы,
несколько исходов одного события и коррелированные ставки.

Profit factor = сумма положительных результатов / модуль суммы отрицательных.
При отсутствии убытков отношение не выводится. Доля крупнейшего выигрыша
считается от суммы положительных результатов, а не от чистой прибыли.
История менее 20 позиций отмечается как малая выборка; это интерфейсная
эвристика, а не статистическое доказательство качества.

Отсутствующие числовые поля не заменяются нулём. Неудачная загрузка показывается
как ошибка, без автоматического перехода на демо. Демо использует только
вымышленные адреса и числа, помеченные в интерфейсе.

Кэш запросов в памяти действует 60 секунд. Таймаут одного запроса — 12 секунд;
одновременно загружаются независимые разделы карточки. Полная загрузка кошелька
может занять до минуты. Все суммы приблизительные и отображаются с округлением.
Это инструмент изучения истории, а не рекомендация повторять сделки.

## Локальные данные

Список наблюдения хранится в `localStorage` данного браузера и не записывается
в репозиторий. Для загрузки публичной истории выбранный адрес передаётся
Polymarket. Очищение данных браузера удаляет список; другой браузер или порт
использует отдельное хранилище. Телеметрии и синхронизации нет.

Папки `local-data/` и `reports/`, а также файлы `.env*` исключены из Git.
Не добавляйте личные списки кошельков и экспортированные отчёты в исходный код.

## Если живые данные недоступны

Откройте `https://data-api.polymarket.com/v2/docs` в вашей сети. Отказ соединения,
ограничение частоты или изменение схемы API отображаются явно. Деморежим
проверяет интерфейс и расчёты, но не подтверждает работоспособность живого API.
Проект не меняет настройки сети и не обходит ограничения доступа.
