# Changelog

## 0.2.0

- Compare consecutive complete position snapshots in the Changes tab.
- Show appearances, disappearances, increases and decreases in share quantity.
- Preserve the last complete baseline across partial or invalid responses.

- Avoid duplicate comparisons for cached data and ignore older snapshots.

Validation: 33 automated tests, plus browser checks using controlled demo responses.
Live Polymarket API connectivity remains unverified.
